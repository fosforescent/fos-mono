# CLAUDE.md

## Directory Summary

Utility library providing common functions, actions, and shared logic for the Fosforescent frontend application.

### Dependencies
- **clsx**: Conditional CSS class name utilities
- **class-variance-authority**: Type-safe CSS variant management
- **@fosforescent/shared/types**: Shared type definitions
- **React**: Framework-specific utilities and patterns

### Data Inputs

#### Utility Parameters
- **CSS Classes**: Class names for conditional application
- **Action Parameters**: Function arguments for common operations
- **Type Definitions**: TypeScript types for utility functions
- **Configuration Objects**: Settings and options for utilities

#### Application State
- **Component Props**: Props passed to utility functions
- **Event Objects**: Browser and React events
- **Form Data**: User input data for processing
- **API Responses**: Server data for transformation

### Data Outputs

#### Utility Functions
- **Class Name Utilities**: Conditional CSS class application
- **Action Creators**: Standardized action functions
- **Data Transformers**: Common data transformation utilities
- **Validation Functions**: Input validation and sanitization

#### Helper Functions
- **Format Utilities**: Data formatting for display
- **Date/Time Helpers**: Date manipulation and formatting
- **String Utilities**: Text processing and manipulation
- **Number Utilities**: Numeric calculation and formatting

### Events Handled
- **User Actions**: Common user interaction patterns
- **Data Processing**: Standard data transformation operations
- **Validation Events**: Input validation and error handling
- **Format Operations**: Data formatting for display

### Data Transformations
- **Raw Data → Formatted Display**: User-friendly data presentation
- **User Input → Validated Data**: Input sanitization and validation
- **API Data → UI State**: Server responses formatted for React components
- **Style Props → CSS Classes**: Conditional styling based on component state

### Utility Categories

#### Styling Utilities
- **cn()**: Conditional class name utility combining clsx and tailwind-merge
- **CSS Variants**: Type-safe component variant management
- **Theme Utilities**: Theme-aware styling functions
- **Responsive Helpers**: Breakpoint and responsive design utilities

#### Action Utilities
- **Common Actions**: Standardized functions for frequent operations
- **Event Handlers**: Reusable event handling patterns
- **API Helpers**: Common API interaction patterns
- **State Updaters**: Standardized state update functions

#### Data Utilities
- **Validation**: Input validation and error handling
- **Formatting**: Data display formatting
- **Transformation**: Data structure conversion
- **Sanitization**: Input cleaning and security

#### Type Utilities
- **Type Guards**: Runtime type checking functions
- **Type Conversion**: Safe type conversion utilities
- **Generic Helpers**: Reusable generic utility functions
- **Assertion Helpers**: Type assertion and validation

### Performance Features
- **Memoization**: Expensive operation caching
- **Debouncing**: Rate-limited function execution
- **Lazy Loading**: On-demand utility loading
- **Tree Shaking**: Unused code elimination

### Development Support
- **TypeScript**: Full type safety for all utilities
- **Error Handling**: Robust error handling patterns
- **Debug Helpers**: Development-time debugging utilities
- **Testing Support**: Test-friendly utility design
