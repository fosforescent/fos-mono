# CLAUDE.md

## Directory Summary

Information display and management components for various data types including budgets, calendars, contacts, documents, media, and resources within the Fosforescent workflow system.

### Dependencies
- **React**: Component framework and hooks
- **@/shared/types**: Shared type definitions
- **../ui/\***: UI component library for consistent styling
- **External Libraries**: Likely calendar, chart, and media handling libraries

### Data Inputs

#### Information Types
- **Budget Data**: Financial information, costs, allocations
- **Calendar Events**: Dates, schedules, deadlines, milestones
- **Contact Information**: People, organizations, communication details
- **Document References**: Files, links, attachments, metadata
- **Media Assets**: Images, videos, audio files
- **Resource Lists**: Tools, materials, equipment inventories

#### Context Data
- **Node Context**: Associated graph nodes and relationships
- **User Permissions**: Access rights for information viewing/editing
- **Project Context**: Related project and workflow information
- **Collaboration Data**: Shared information and team access

### Data Outputs

#### Information Displays
- **Budget Visualizations**: Charts, tables, cost breakdowns
- **Calendar Views**: Timeline, schedule, event displays
- **Contact Lists**: People directories, communication logs
- **Document Browsers**: File listings, preview capabilities
- **Media Galleries**: Image/video galleries with metadata
- **Resource Inventories**: Available tools and materials

#### Interactive Elements
- **Edit Capabilities**: In-place editing of information
- **Search and Filter**: Finding specific information items
- **Sorting Options**: Organizing information by various criteria
- **Export Functions**: Data export in various formats

### Events Handled
- **Information Updates**: Adding, editing, deleting information items
- **View Changes**: Switching between different display modes
- **Search Operations**: Filtering and finding information
- **Media Operations**: Upload, preview, download media files
- **Calendar Interactions**: Event creation, editing, scheduling

### Data Transformations
- **Raw Data → Visual Displays**: Information formatted for user presentation
- **User Input → Structured Data**: Form inputs converted to structured information
- **Search Queries → Filtered Results**: Search terms converted to filtered displays
- **Export Requests → Formatted Output**: Information converted for external use

### Component Categories

#### Financial Components
- **Budget**: Financial planning and cost tracking
- **Invoice**: Billing and payment information
- **Cost Analysis**: Financial reporting and analysis

#### Time Management
- **Calendar**: Date-based event and schedule management
- **Timeline**: Project timeline and milestone tracking
- **Scheduling**: Resource and time allocation

#### Contact Management
- **Contacts**: People and organization directory
- **Communication**: Message and interaction history
- **Team Management**: Collaboration and role information

#### Document Management
- **Document**: File organization and access
- **Folders**: Hierarchical file organization
- **Links**: URL and reference management
- **Version Control**: Document versioning and history

#### Media Management
- **Images**: Image gallery and editing capabilities
- **Videos**: Video library and playback
- **Media Browser**: Multi-media asset management

#### Resource Management
- **Inventory**: Equipment and material tracking
- **Resources**: Tool and asset allocation
- **Availability**: Resource scheduling and booking

#### Analytics
- **Probability**: Risk and probability analysis
- **Reports**: Information summarization and reporting
- **Metrics**: Performance and progress tracking

### Display Patterns
- **List Views**: Tabular information display
- **Grid Views**: Card-based information layout
- **Detail Views**: Full information display with editing
- **Summary Views**: Condensed information overview
- **Search Results**: Filtered and sorted information lists

### Integration Features
- **Graph Integration**: Information linked to workflow nodes
- **Cross-References**: Information linked across different types
- **Export Capabilities**: Information export in standard formats
- **Import Functions**: Bulk information import from external sources
- **Collaboration**: Shared information access and editing
